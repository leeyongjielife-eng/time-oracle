# 此刻签 · V2 可交互设计稿

本轮作为设计评审版本，独立于 web/，未部署线上。打开 index.html 即可体验，也可运行 `python3 -m http.server 4174 --directory design-v2`。

## 设计
午夜蓝紫、月光、香槟金与纸质卡片。桌面左右分栏，手机单栏与固定底部导航。名称暂定“此刻签”。

首页及重问界面采用《周易·蒙》原句：“初筮告，再三渎，渎则不告。” 配以“留住初问，把余下的时间交给行动”。显化页的“心之所向，行之所往”为界面文案，不标注古籍出处。

## 可以体验的流程
- 秒数取签、原帖 60 条签文、重复问题提示、回看原签、收藏、销毁。
- 由签文创建心愿或独立创建；分类、可选下一小步。
- 可随时退出的 20 秒静心；结束时可留下一段记录，不提供实现概率。
- 进展日志、已实现纪念、放下、恢复、删除确认。
- 空状态可手动添加 2 个明确标注的示例，默认没有预置私人记录。
